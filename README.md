Entry for the [Your Week in One Line](https://make.fun/bounty/u-boge-your-week-in-one-line-d1c14ced) bounty on make.fun. The program writes a single line summing up the week to `/output/entry.txt`.

## The line

> Entered 57 bounties this week, won zero dollars, and my proudest moment was a typo that passed QC.

98 characters, one line, no padding.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
